# 小说解析 RAG 系统 — 数据库设计

> 版本：v1.0（配套《需求文档》《需求分析》）
> 数据库：PostgreSQL（开发期可用 SQLite 兼容子集）
> 命名规范：所有表以 `story_` 前缀；版本更替以 `Vxx_功能表述` 分段
> 隔离原则：业务表均带 `owner_id`，Repository 层强制按当前用户过滤（无角色权限分级）

---

## 设计说明

- **字符集**：`UTF8`；**排序规则**：`zh_cn` 友好（`C` 或 `und-x-icu`）。
- **通用字段**：大部分表含 `id`(PK, bigserial)、`owner_id`(用户隔离)、`created_at`、`updated_at`。
- **JSON 字段**：标签、画像、元数据等使用 `jsonb` 便于扩展查询。
- **软删除**：`deleted_at` 时间戳（NULL 表示未删），避免误删关联数据。
- **向量**：切片向量存向量库（Chroma/Milvus），关系库仅存 `vector_id` 引用，不存向量本身。
- **加密**：`story_llm_config.api_key` 用 Fernet 对称加密后存 `text`。

## V1_基础数据（核心业务）

### story_user（用户）
```sql
CREATE TABLE story_user (
    id          BIGSERIAL PRIMARY KEY,
    username    VARCHAR(64)  NOT NULL UNIQUE,
    password    VARCHAR(255) NOT NULL,          -- bcrypt 哈希
    name        VARCHAR(64),                    -- 展示名
    avatar      VARCHAR(512),                   -- MinIO object_key / URL
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
-- 仅用于标识创建者 / 数据隔离，不做权限分级
```

### story_novel（小说，顶层隔离单元）
```sql
CREATE TABLE story_novel (
    id          BIGSERIAL PRIMARY KEY,
    owner_id    BIGINT NOT NULL REFERENCES story_user(id),
    name        VARCHAR(255) NOT NULL,
    author      VARCHAR(128),
    summary     TEXT,
    cover       VARCHAR(512),                   -- MinIO object_key
    status      VARCHAR(16)  NOT NULL DEFAULT 'serial',  -- serial=连载 finished=完结
    tags        JSONB        NOT NULL DEFAULT '[]',
    file_hash   CHAR(64),                       -- 上传文件 sha256，去重用
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at  TIMESTAMPTZ,
    UNIQUE (owner_id, name)
);
CREATE INDEX idx_novel_owner ON story_novel(owner_id) WHERE deleted_at IS NULL;
```

### story_chapter（章节）
```sql
CREATE TABLE story_chapter (
    id          BIGSERIAL PRIMARY KEY,
    novel_id    BIGINT NOT NULL REFERENCES story_novel(id),
    owner_id    BIGINT NOT NULL REFERENCES story_user(id),
    title       VARCHAR(255),
    chapter_no  INT          NOT NULL DEFAULT 0,  -- 排序号
    content     TEXT         NOT NULL,
    word_count  INT          NOT NULL DEFAULT 0,
    char_start  INT,                             -- 在原文档中的字符区间
    char_end    INT,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at  TIMESTAMPTZ
);
CREATE INDEX idx_chapter_novel ON story_chapter(novel_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_chapter_owner ON story_chapter(owner_id);
```

### story_knowledge_base（知识库）
```sql
CREATE TABLE story_knowledge_base (
    id          BIGSERIAL PRIMARY KEY,
    novel_id    BIGINT NOT NULL REFERENCES story_novel(id),
    owner_id    BIGINT NOT NULL REFERENCES story_user(id),
    name        VARCHAR(255) NOT NULL,
    scope       VARCHAR(16) NOT NULL DEFAULT 'private', -- private/team/public(仅展示)
    config      JSONB        NOT NULL DEFAULT '{}',
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at  TIMESTAMPTZ,
    UNIQUE (novel_id, name)
);
```

### story_document（文档）
```sql
CREATE TABLE story_document (
    id          BIGSERIAL PRIMARY KEY,
    kb_id       BIGINT NOT NULL REFERENCES story_knowledge_base(id),
    novel_id    BIGINT NOT NULL REFERENCES story_novel(id),
    owner_id    BIGINT NOT NULL REFERENCES story_user(id),
    name        VARCHAR(255) NOT NULL,
    doc_type    VARCHAR(16) NOT NULL,           -- txt/epub/pdf/docx
    object_key  VARCHAR(512),                   -- MinIO 原文件 key
    file_hash   CHAR(64),
    status      VARCHAR(16) NOT NULL DEFAULT 'pending', -- pending/parsing/done/failed
    error       TEXT,
    word_count  INT DEFAULT 0,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at  TIMESTAMPTZ
);
CREATE INDEX idx_doc_kb ON story_document(kb_id) WHERE deleted_at IS NULL;
```

### story_chunk（切片）
```sql
CREATE TABLE story_chunk (
    id          BIGSERIAL PRIMARY KEY,
    doc_id      BIGINT NOT NULL REFERENCES story_document(id),
    novel_id    BIGINT NOT NULL REFERENCES story_novel(id),
    kb_id       BIGINT NOT NULL REFERENCES story_knowledge_base(id),
    owner_id    BIGINT NOT NULL REFERENCES story_user(id),
    chapter_id  BIGINT REFERENCES story_chapter(id),
    idx         INT          NOT NULL,          -- 切片序号
    content     TEXT         NOT NULL,
    word_count  INT          DEFAULT 0,
    vector_id   VARCHAR(128),                   -- 向量库返回 ID
    meta        JSONB        NOT NULL DEFAULT '{}', -- 页码/字符区间/来源标题
    disabled    BOOLEAN      NOT NULL DEFAULT false, -- 屏蔽不参与检索
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_chunk_kb ON story_chunk(kb_id);
CREATE INDEX idx_chunk_chapter ON story_chunk(chapter_id);
CREATE INDEX idx_chunk_owner ON story_chunk(owner_id);
```


### story_entity（实体 / 人物）
```sql
CREATE TABLE story_entity (
    id          BIGSERIAL PRIMARY KEY,
    novel_id    BIGINT NOT NULL REFERENCES story_novel(id),
    owner_id    BIGINT NOT NULL REFERENCES story_user(id),
    name        VARCHAR(128) NOT NULL,
    type        VARCHAR(16) NOT NULL DEFAULT 'character', -- character/place/org
    profile     JSONB        NOT NULL DEFAULT '{}', -- 性别/身份/性格/外貌/口头禅
    avatar      VARCHAR(512),                   -- MinIO object_key
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    deleted_at  TIMESTAMPTZ,

);

```

### story_relation（关系）
```sql
CREATE TABLE story_relation (
    id          BIGSERIAL PRIMARY KEY,
    novel_id    BIGINT NOT NULL REFERENCES story_novel(id),
    owner_id    BIGINT NOT NULL REFERENCES story_user(id),
    source_id   BIGINT NOT NULL REFERENCES story_entity(id),
    target_id   BIGINT NOT NULL REFERENCES story_entity(id),

    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (source_id, target_id, type)
);
CREATE INDEX idx_relation_novel ON story_relation(novel_id);
```

```sql
CREATE TABLE story_conversation_message (
```

### story_llm_config（大模型配置）
```sql
CREATE TABLE story_llm_config (
    id          BIGSERIAL PRIMARY KEY,
    owner_id    BIGINT REFERENCES story_user(id), -- NULL 表示全局
    name        VARCHAR(128) NOT NULL,
    provider    VARCHAR(32) NOT NULL,           -- OpenAI/Claude/Ollama/智谱/通义
    model       VARCHAR(128) NOT NULL,
    base_url    VARCHAR(512),
    api_key     TEXT,                           -- Fernet 加密存储
    llm_type    VARCHAR(16) NOT NULL DEFAULT 'chat', -- chat/embed/image
    is_default  BOOLEAN NOT NULL DEFAULT false, -- 该类型默认模型
    status      VARCHAR(16) NOT NULL DEFAULT 'active',
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

```sql
CREATE TABLE story_skill (
```

### story_mcp_config（MCP 配置）
```sql
CREATE TABLE story_mcp_config (

    name        VARCHAR(128) NOT NULL,
```

## 索引与性能补充

- 所有 `owner_id` 字段建索引，支撑多用户隔离查询。
- `story_chunk` 按 `kb_id / chapter_id / owner_id` 组合查询频繁，已建单列索引；超大数据量可加 `(novel_id, disabled)` 部分索引。
- `story_llm_usage` 写入频繁，仪表盘聚合查询走 `date_trunc` + 物化视图或缓存，避免实时全表扫。
- 向量检索走向量库，关系库仅维护 `vector_id` 映射。

### story_chapter_drama（章节漫剧）

```sql
CREATE TABLE story_chapter_drama (
    id              BIGSERIAL PRIMARY KEY,
    novel_id       BIGINT       NOT NULL REFERENCES story_novel(id),
    owner_id       BIGINT       NOT NULL REFERENCES story_user(id),
    title          VARCHAR(255),
    chapter_from   INT          NOT NULL,                       -- 起始章节序号
    chapter_to     INT          NOT NULL,                       -- 结束章节序号（>= chapter_from，跨度<=5）
    character_ids  JSONB        NOT NULL DEFAULT '[]',          -- 出场角色 story_character.id 列表
    summary        VARCHAR(1024),
    extra          JSONB        NOT NULL DEFAULT '{}',
    created_at     TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at     TIMESTAMPTZ  NOT NULL DEFAULT now(),
    deleted_at     TIMESTAMPTZ,
    CONSTRAINT chk_drama_span CHECK (chapter_to >= chapter_from AND (chapter_to - chapter_from + 1) <= 5)
);
```
